React ​

React 是 Meta 开源的前端框架，和 Vue 解决同一个问题：数据变了页面自动跟着变。写法上它没有模板文件，组件就是一个返回「JSX」的函数——JSX 可以理解成写在 JS 里的 HTML。国内用它搭后台通常配 Ant Design（蚂蚁开源的组件库），和 Vue 配 Element Plus 是一个路子。

这篇和 Vue 那篇走完全一样的流程：建项目、目录、路由布局、调接口、部署，只是把 Element Plus 换成 Ant Design。两边对照着看，前端这两大主流的差别就摸清了。前置条件：装好 Node.js，见 Node.JS 安装。

建项目 ​

React 官方已经不推荐老的 create-react-app，新项目一律用 Vite 模板：

bash

路由和布局 ​

React 官方不管路由，社区标准方案是 react-router-dom。入口先包上 BrowserRouter，顺便用 antd 的 ConfigProvider 把组件换成中文（不配的话分页、日期全是英文）。main.tsx 改成：

tsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { BrowserRouter } from 'react-router-dom'
import { ConfigProvider } from 'antd'
import zhCN from 'antd/locale/zh_CN'
import App from './App.tsx'

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <BrowserRouter>
      <ConfigProvider locale={zhCN}>
        <App />
      </ConfigProvider>
    </BrowserRouter>
  </StrictMode>
)

App.tsx 整个换成布局加路由：

tsx
import { Routes, Route, useLocation, useNavigate } from 'react-router-dom'
import { Layout, Menu } from 'antd'
import Home from './views/Home'
import Users from './views/Users'

export default function App() {
  const location = useLocation()
  const navigate = useNavigate()

  return (
    <Layout style={{ minHeight: '100vh' }}>
      <Layout.Sider width={200}>
        <Menu
          selectedKeys={[location.pathname]}
          onClick={({ key }) => navigate(key)}
          items={[
            { key: '/', label: '首页' },
            { key: '/users', label: '用户管理' }
          ]}
        />
      </Layout.Sider>
      <Layout.Content style={{ padding: 24 }}>
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/users" element={<Users />} />
        </Routes>
      </Layout.Content>
    </Layout>
  )
}

和 Vue 版对照：el-menu 的 router 属性在这里换成了 useNavigate 手动跳转，菜单点击的 key 就是路径；useLocation 拿当前路径来控制菜单高亮，刷新不丢。Routes/Route 负责 URL 和组件的对应，以后加页面就是 views 下建个组件、加一行 Route。

这里顺带记几条 JSX 和 HTML 不同的规矩：class 写成 className，标签必须闭合（<Layout.Sider /> 这种也要斜杠），行内样式传的是 JS 对象——外面一层花括号表示表达式，里面一层是样式对象，所以代码里看到的是双层花括号套着写。写错保存后编辑器马上报红，Vite 终端里也会给出位置。

调后端接口 ​

axios 封装是和 Vue 篇同款套路，src/utils/request.ts（utils 目录自己建）：

ts
import axios from 'axios'

const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE,
  timeout: 10000
})

// 请求拦截器：每个请求自动带上 token
request.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截器：直接返回后端的数据体，顺便统一处理登录过期
request.interceptors.response.use(
  res => res.data,
  err => {
    if (err.response?.status === 401) {
      localStorage.removeItem('token')
      location.href = '/login'
    }
    return Promise.reject(err)
  }
)

export default request

用户页面接数据，还是约定后端有 GET /api/users，返回 { "code": 200, "data": [...] }。src/views/Users.tsx 换成：

tsx
import { useEffect, useState } from 'react'
import { Card, Table } from 'antd'
import request from '../utils/request'

interface User {
  id: number
  name: string
  email: string
}

export default function Users() {
  const [list, setList] = useState<User[]>([])
  const [loading, setLoading] = useState(false)

  useEffect(() => {
    setLoading(true)
    request.get('/users').then(res => {
      setList(res.data)
      setLoading(false)
    })
  }, [])

  return (
    <Card>
      <Table
        rowKey="id"
        loading={loading}
        dataSource={list}
        columns={[
          { title: 'ID', dataIndex: 'id' },
          { title: '姓名', dataIndex: 'name' },
          { title: '邮箱', dataIndex: 'email' }
        ]}
      />
    </Card>
  )
}

两个 React 特有的点：

useState 创建状态，setList 是改它的唯一正规途径。直接 list.push(...) 页面不会有任何反应，必须 setList 换一个新数组 React 才会重新渲染，刚从 Vue 过来的人最容易在这翻车。

useEffect 第二个参数传 [] 表示只在组件挂载后执行一次，相当于 Vue 的 onMounted；这个数组是依赖列表，里面的值变了 useEffect 会重新执行，调接口的场景大部分传 [] 就对了。另外开发模式下 StrictMode 会让组件跑两遍，控制台里看到同一个接口请求了两次是正常现象，build 出来的产物不受影响。

响应拦截器已经剥掉 axios 那层，res 拿到的直接是后端返回体，res.data 就是 JSON 里的 data 字段，和 Vue 篇一致。写增删改查同样是把 request.get 换成 request.post / request.put / request.delete，数据作为第二个参数。

打包部署 ​

建 .env.production：

text
VITE_API_BASE=/api
1

然后构建：

bash
npm run build
1

产物在 dist/。nginx 配置和 Vue 篇同款，一个静态托管加一个 /api 转发，try_files 那行同样别删（history 路由刷新 404 的锅，找不到文件就回退 index.html 让前端路由接管）：

nginx
server {
    listen 80;
    server_name your.domain.com;

    location / {
        root /usr/share/nginx/html;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://localhost:5000;
    }
}
